

1️⃣ File & Directory Management (Daily Use)**
```bash
ls          # List files
ls -l       # Long format (permissions, size, date)
ls -la      # Show hidden files too
tree        # Directory tree view
pwd         # Print working directory
cd          # Change directory (cd -, cd ~, cd /)
pushd /popd # Directory stack (quick switching)
```

```bash
cp          # Copy file
cp -r       # Copy recursively (directories)
mv          # Move/rename
rm          # Remove file
rm -rf      # Force recursive remove (DANGEROUS)
install     # Copy + set permissions/mode
```

```bash
touch       # Create empty file or update timestamp
stat        # Detailed file info (permissions, inode, etc.)
file        # Detect file type
realpath    # Resolve absolute path
basename    # Get filename from path
dirname     # Get directory from path
```

### **2️⃣ File Viewing & Reading**
```bash

more        # Simple pager
head        # First 10 lines

tail -f     # Follow file in real-time (logs)
watch       # Run command repeatedly and show output
```

```bash
nl          # Number lines
wc          # Word/Line/Character count
```

### **3️⃣ File Search & Locate**
```bash
find        # Search files by name, size, time, type etc.
locate      # Fast search using database
updatedb    # Update locate database
which       # Show full path of executable
whereis     # Show binary + source + man pages
type        # Show how command is interpreted (alias, builtin, etc.)
```

**Example:**
```bash
find /var/log -name "*.log" -mtime -1
which docker
```
